<summary><strong>1. ArduPilot SITL і QGroundControl і Структура репозиторію</strong></summary>

Перевірене середовище - macOS | 15.7.3 (24G419), Apple Silicon

### Встановлення ArduPilot

```bash
git clone --recurse-submodules https://github.com/ArduPilot/ardupilot.git
cd ardupilot

python3.11 -m venv .venv
source .venv/bin/activate
/bin/bash ./Tools/environment_install/install-prereqs-mac.sh
```

### Збірка Copter SITL

```bash
source .venv/bin/activate
./waf configure --board sitl
./waf copter
```

### Запуск Copter SITL

```bash
source .venv/bin/activate
./Tools/autotest/sim_vehicle.py \
  -v ArduCopter \
  -f quad \
  --console \
  --out=127.0.0.1:14551
```

MAVProxy автоматично використовує UDP-порт `14550` для<br>
QGroundControl. Додатково налаштовано UDP-порт `14551`.

### Установлення і перевірка QGroundControl

```bash
brew install --cask qgroundcontrol
open -a QGroundControl
```

### 1. Як виглядає MAVLink-пакет

Навчальна схема для **MAVLink 1**, нумерація байтів починається з `0`.

```text
┌────────┬────────┬────────┬────────┬────────┬────────┬─────────────┬─────────┐
│ magic  │  len   │  seq   │ sysid  │ compid │ msgid  │   payload   │   CRC   │
│ 1 Byte │ 1 Byte │ 1 Byte │ 1 Byte │ 1 Byte │ 1 Byte │ 0–255 Bytes │ 2 Bytes │
└────────┴────────┴────────┴────────┴────────┴────────┴─────────────┴─────────┘
└────────────────── заголовок: 6 Bytes ──────────────┘
```

| Поле | Що означає |
|---|---|
| `magic` | Початок пакета: `FE` для MAVLink 1 |
| `len` | Розмір payload |
| `seq` | Лічильник пакетів |
| `sysid`, `compid` | Хто надіслав |
| `msgid` | Яке повідомлення передається |
| `payload` | Дані цього повідомлення |
| `CRC` | Перевірка пошкодження |

**Загальний розмір = payload + 8 Bytes.**

### 2. Що означає `GUID_OPTIONS=8`

`GUID_OPTIONS` — **параметр ArduPilot**, а не повідомлення. Він налаштовує поведінку режиму `GUIDED`.

```text
Біт:      7     6     5     4     3     2     1     0
       ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
Вага:  │ 128 │  64 │  32 │  16 │   8 │   4 │   2 │   1 │
       ├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
Стан:  │  0  │  0  │  0  │  0  │  1  │  0  │  0  │  0  │
       └─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘

       00001000₂ = 8 = 0x08
```

| Налаштування | Як ArduPilot трактує поле `thrust` |
|---|---|
| `GUID_OPTIONS=0` | Задає **швидкість підйому або зниження**: `0.5` — без зміни висоти |
| `GUID_OPTIONS=8` | Задає **нормалізовану тягу `0…1`**: `0.5` — половина шкали тяги |

За `GUID_OPTIONS=0` число `0.6` не означає `0.6 м/с`: швидкість визначається за налаштуваннями ArduPilot.

Інші опції маски:

| Значення | Що вмикає |
|---:|---|
| `1` | Армінг із пульта в `GUIDED` |
| `4` | Ігнорування yaw із пульта |
| **`8`** | **Трактування `thrust` як тяги** |
| `16` | Вимкнення корекції горизонтальної позиції |
| `32` | Вимкнення корекції горизонтальної швидкості |
| `64` | Планування траєкторії до цільової позиції |
| `128` | Розворот за вітром |

Опції можна поєднувати: `12 = 8 + 4`. **У нашому ТЗ потрібно саме `8`.**

### 3. Як виглядає `SET_ATTITUDE_TARGET`

`msgid = 82 = 0x52`. У MAVLink 1 payload займає **39 Bytes**, повний пакет — **47 Bytes**.

Поля payload у порядку передачі:

```text
┌─────────┬──────────┬──────────┬──────────┬──────────┬─────────┬────────┬────────┬───────────┐
│   час   │    q     │roll rate │pitch rate│ yaw rate │ thrust  │ target │ target │ type_mask │
│         │          │          │          │          │         │ system │ comp.  │           │
│ 4 Bytes │ 16 Bytes │ 4 Bytes  │ 4 Bytes  │ 4 Bytes  │ 4 Bytes │ 1 Byte │ 1 Byte │  1 Byte   │
└─────────┴──────────┴──────────┴──────────┴──────────┴─────────┴────────┴────────┴───────────┘
```

`q` — орієнтація, `rates` — швидкості обертання, `thrust` — керування тягою. `type_mask` визначає, які поля ігнорувати.

```text
Біт:      7      6      5      4      3      2      1      0
       ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
Стан:  │  1   │  0   │  0   │  0   │  0   │  1   │  1   │  1   │
       └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
          │      │                           │      │      │
       ігнор.  thrust                      ігнор. ігнор. ігнор.
         q    активний                       yaw  pitch  roll

       10000111₂ = 135 = 0x87
```

| `type_mask` | Значення за MAVLink |
|---|---|
| `0x07` = `7` | Орієнтація + thrust |
| `0x80` = `128` | Кутові швидкості + thrust |
| `0x87` = `135` | Тільки thrust |

Підтримка `0x87` нашою версією ArduPilot ще потребує перевірки в SITL: документація Copter указує варіанти `0x07` і `0x80`.
